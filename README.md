# سامانه گفت‌وگوی آنلاین

یک برنامهٔ چت فارسی مبتنی بر Node.js، Express، MySQL و WebSocket که امکان ثبت‌نام، ساخت چت، عضویت با لینک، ارسال پیام و رسانه و مدیریت اعضا را فراهم می‌کند.

## امکانات

- ثبت‌نام و ورود با توکن JWT
- ساخت چت توسط هر کاربر؛ سازنده به‌صورت خودکار مدیر چت می‌شود
- پیوستن کاربران دیگر با لینک چت
- پیام‌رسانی بلادرنگ با WebSocket
- پاسخ، ویرایش، حذف، سنجاق‌کردن و واکنش به پیام‌ها
- پیام صوتی و بارگذاری رسانه
- شمارش پیام‌های خوانده‌نشده و منشن‌ها
- مدیریت اجازهٔ ارسال پیام و رسانه توسط مدیر چت
- رابط فارسی واکنش‌گرا با حالت روشن و تاریک

## پیش‌نیازها

- Node.js نسخهٔ ۱۸ یا جدیدتر
- npm
- MySQL نسخهٔ ۸ یا جدیدتر

## راه‌اندازی

۱. مخزن را دریافت و وارد پوشهٔ پروژه شوید:

```bash
git clone git@github.com:Ara-13/chat.git
cd chat
```

۲. وابستگی‌ها را نصب کنید:

```bash
npm install
```

۳. یک پایگاه‌داده در MySQL بسازید:

```sql
CREATE DATABASE chat_app
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

۴. فایل تنظیمات محیطی را بسازید:

```bash
cp .env.example .env
```

سپس مقدارهای فایل `.env` را متناسب با MySQL خود تغییر دهید:

```dotenv
PORT=5000
DB_HOST=127.0.0.1
DB_NAME=chat_app
DB_USER=root
DB_PASS=your_mysql_password
JWT_SECRET=replace_with_a_long_random_secret
```

برای ساخت یک مقدار امن برای `JWT_SECRET` می‌توانید از دستور زیر استفاده کنید:

```bash
openssl rand -hex 32
```

۵. برنامه را اجرا کنید:

```bash
npm start
```

در حالت توسعه و با راه‌اندازی مجدد خودکار:

```bash
npm run dev
```

سپس نشانی [http://localhost:5000](http://localhost:5000) را باز کنید. مدل‌های دیتابیس هنگام اجرای برنامه با Sequelize ساخته یا همگام می‌شوند.

## اجرای آزمون‌ها

```bash
npm test
```

## ساخت اولین چت

پس از ثبت‌نام و ورود، در صفحهٔ «چت‌های من» روی دکمهٔ «ساخت چت» بزنید و نام چت را وارد کنید. سازنده مدیر چت است. برای دعوت دیگران، نشانی همان صفحهٔ چت را برایشان بفرستید؛ کاربر واردشده می‌تواند از صفحهٔ پیوستن عضو شود.

## ساختار مهم پروژه

```text
controllers/   منطق درخواست‌های HTTP
middlewares/   احراز هویت و کنترل دسترسی
models/        مدل‌های Sequelize
public/        رابط کاربری سمت مرورگر
routes/        مسیرهای وب و API
test/          آزمون‌های خودکار
utils/         توابع کمکی مستقل
ws/            سرور و رویدادهای WebSocket
```

## نکات امنیت و استقرار

- فایل `.env` و رسانه‌های بارگذاری‌شده در گیت ثبت نمی‌شوند.
- در محیط عملیاتی از `JWT_SECRET` طولانی و تصادفی و کاربر محدودشدهٔ MySQL استفاده کنید.
- همگام‌سازی فعلی Sequelize با `alter: true` برای توسعه مناسب است. برای استقرار جدی بهتر است migrationهای نسخه‌بندی‌شده جایگزین آن شوند.
- پوشهٔ `storage/uploads` در اجرای محلی نگه‌داری می‌شود؛ برای چند سرور یا استقرار ابری از فضای ذخیره‌سازی اشتراکی استفاده کنید.
